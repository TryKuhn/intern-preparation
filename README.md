Курс по подготовке к стажировке на C++ с нуля

# План

## Фаза 0 — Окружение и фундамент C++

### 0.1 Bash
- Навигация и файлы: `cd/ls/pwd/cp/mv/rm/mkdir`, абсолютные/относительные пути.
- Просмотр и поиск: `cat/less/head/tail`, `grep`, `find`, wildcards (`*`, `?`).
- **Regex (через `grep -E`/`egrep`)**: метасимволы `. * + ? [] ^ $ () |`, классы символов (`[0-9]`, `\d`, `\w`), якоря, группы и квантификаторы, жадность; basic vs extended regex; `sed`/`awk`.
- Пайпы и редиректы: `|`, `>`, `>>`, `2>&1`, `<`; цепочки `&&` / `||`.
- Права и исполнение: `chmod +x`, shebang `#!/bin/bash`; переменные окружения и `$PATH`.
- Процессы: `ps`, `top`, `kill`, фоновые задачи `&`.

### 0.2 Git
- Модель: рабочая директория + staging + commit + remote; что такое `HEAD`.
- База: `init/clone`, `add/commit/status/diff/log`, `.gitignore`.
- Ветки: `branch/switch/checkout`, **merge vs rebase**, разрешение конфликтов.
- Удалёнка: `push/pull/fetch`, PR-флоу на GitHub.
- Откаты: `restore`, `reset` (soft/mixed/hard), `revert` — и чем отличаются.
  
### 0.3 Тулчейн и модель сборки
- g++/clang, этапы: препроцессор + компиляция + линковка; объектные файлы.
- Базовый CMake, `gdb`, как читать ошибки компилятора и линкера.
- Тонкости: ODR (правило одного определения); `#pragma once`/header guards; форвард-декларации и неполные типы; `inline` (в т.ч. inline-переменные C++17) ; `static` = внутренняя линковка.
  
### 0.4 Память и типы
- Стек vs куча, как живёт переменная, `sizeof`, `size_t`.
- Тонкости: представление целых (доп. код), **знаковое переполнение = UB**; беззнаковое оборачивается; `-1 < 0u` → false; целочисленные промоушены; `size_t` - подтекание в циклах; знаковость `char` — impl-defined; float: `==`/NaN/точность.
  
### 0.5 Ссылки и указатели
- Передача по значению/ссылке/указателю; арифметика указателей, распад массива; `nullptr`.
- Тонкости: категории значений lvalue/rvalue (строго — glvalue/prvalue/xvalue); висячая ссылка; продление жизни temporary при `const&`; `auto` отбрасывает ссылки и верхний `const`, `decltype` — нет.
  
### 0.6 Динамическая память
- `new/delete`, утечки, висячие указатели, double-free.
- Тонкости: `delete` vs `delete[]`; **use-after-free**, dangling; начало/конец времени жизни объекта; placement new; выравнивание/паддинг, `alignof`/`alignas`.
  
### 0.7 RAII и умные указатели
- `unique_ptr`, `shared_ptr`, `weak_ptr`; кастомные делитеры.
- Тонкости: сырой указатель = невладеющий; `shared_ptr` — control block и **атомарный счётчик** (стоит денег); `weak_ptr` рвёт циклы, цикл shared_ptr = утечка; `make_shared` vs `new` — одна аллокация, weak держит блок; RAII/scope guard как защита от утечек при исключении; `enable_shared_from_this`.
  
### 0.8 const-корректность
- `const&` для передачи без копий, `const`-методы, `mutable`.
- Тонкости: верхний vs низкоуровневый `const`; `const int*` vs `int* const`; логическая vs битовая константность; `constexpr`/`consteval`/`constinit` (C++20); `volatile` — что делает и что **не** делает (не для потоков).
  
### 0.9 ООП ч.1 — классы и инициализация
- class/struct, инкапсуляция (private/public/protected), конструкторы/деструкторы, список инициализации.
- Тонкости: **порядок инициализации членов = порядок объявления**, не списка (варнинг); `explicit` и неявные преобразования; `{}`-инициализация и запрет сужения; ловушка `vector<int>{3}` vs `vector<int>(3)`; `auto x = {1,2}` -> `initializer_list`; делегирующие/наследуемые конструкторы; magic statics (потокобезопасная инициализация static-локалов с C++11); most vexing parse; SIOF.
  
### 0.10 ООП ч.2 — копирование и перемещение
- Тонкости: **rule of 0/3/5**; `=default`/`=delete`; copy vs move; `std::move` — **просто каст** к rvalue; rvalue-ссылка `&&`, moved-from состояние; copy elision / RVO / NRVO, обязательный elision с C++17; forwarding (universal) ссылка `T&&` vs rvalue-ссылка; свёртка ссылок (`& &&`→`&`, `&& &&`→`&&`); `std::forward` и perfect forwarding; **`noexcept` у move-конструктора -> `vector` переезжает, а не копирует** при реаллокации.
  
### 0.11 ООП ч.3 — наследование и полиморфизм
- Виртуальные функции, абстрактные классы, виртуальный деструктор.
- Тонкости: **vtable/vptr**; `override`/`final`; slicing; виртуальный деструктор — зачем; вызов виртуальной из конструктора/деструктора резолвится на текущий класс; **аргументы по умолчанию у виртуальных связываются статически**; сокрытие имён, `using` для подъёма перегрузок; ромб/виртуальное наследование.
  
### 0.12 Шаблоны (база) + тур по UB
- Шаблоны функций/классов, вывод аргументов, базовая специализация (нужны под свои контейнеры). **Глубина шаблонов вынесена в отдельный модуль 4.0 перед моками** — здесь только рабочий минимум.
- Тонкости: специализация (полная/частичная); `if constexpr` как простое ветвление. UB-тур: **UB vs unspecified vs implementation-defined**; порядок вычисления аргументов — unspecified, `i = i++` — UB; strict aliasing и опасность `reinterpret_cast`; четыре каста (static/dynamic/const/reinterpret).

## Фаза 1 — STL и свои реализации структур данных

### 1.1 Тур по STL + сложности
- vector, string, array, deque, list, map/set, unordered_map/set, stack, queue, priority_queue.
- Итераторы, `<algorithm>` (sort, lower_bound, unique).
- Таблица сложностей операций.
- Тонкости: **лямбды** (захват по значению/ссылке, init-capture C++14, `mutable`, generic, висячий `this`) — нужны для компараторов; `std::string_view` и его **висячесть**; `std::optional`/`std::variant`.
- **`std::regex`** (`<regex>`): `regex_match`/`regex_search`/`regex_replace`, группы захвата (`smatch`), грамматика ECMAScript — синтаксис уже знаком из `grep`, разбираем только API.
- **Важная оговорка:** `std::regex` заметно медленный и тяжёлый — годится для валидации/конфигов, не для горячих путей (там RE2/ручной парсинг).
  
### 1.2 Амортизированный анализ на примере vector
- Удвоение capacity, почему push_back амортизированно O(1).
- Своя реализация динамического массива.
   
### 1.3 Связные списки
- Свой singly/doubly linked list, вставка/удаление за O(1) по итератору.
   
### 1.4 Стек и очередь
- Своя реализация на массиве и на списке.
- Кольцевой буфер.

### 1.5 Хеш-таблица под капотом ч.1
- Хеш-функции, коллизии, **chaining vs open addressing**, load factor.
- Своя реализация с chaining.
   
### 1.6 Хеш-таблица под капотом ч.2.
- Рехеширование, амортизированно O(1), **худший случай O(n)**, hash-флуд.
    
### 1.7. Деревья поиска
- BST: вставка/поиск/удаление, вырождение
- Концептуально — балансировка (AVL/красно-чёрное), что использует `std::map`.
    
### 1.8 Куча
- Своя бинарная куча, `push`/`pop`/`heapify`, как устроен `priority_queue`.
    
### 1.9 Сводное занятие
- Когда какую структуру брать; обоснование выбора через сложности.
- Тонкости: перегрузка операторов (возврат `&` из `operator=`), `operator[]` vs `.at()`, spaceship `<=>` (C++20); ADL/поиск Кёнига.

## Фаза 2 — Алгоритмы и структуры данных, ядро

### Сложность и оценка
- Big-O/Θ/Ω, оценка по лимитам, прикидка «зайдёт ли».

### Массивы/строки/
- Два указателя, скользящее окно.

### Сортировки
- merge/quick/heap своими руками, counting/radix, `std::sort`, стабильность, компараторы.

- Подмножества/перестановки, бэктрекинг, отсечения.
