### Big-O нотация

**O(f(n))**: алгоритм выполняет не более C×f(n) операций при n → ∞ (для некоторой константы C).

Основные классы сложности (от быстрого к медленному):
```
O(1) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n) < O(n!)
```

### Таблица «зайдёт ли за 1 секунду»

| N | Максимальная сложность |
|---|---|
| ≤ 10 | O(n!) |
| ≤ 20 | O(2^n) |
| ≤ 500 | O(n³) |
| ≤ 5 000 | O(n²) |
| ≤ 100 000 | O(n log n) |
| ≤ 10⁸ | O(n) |
| ≤ 10¹⁸ | O(log n) или O(√n) |

Правило: ~10⁸ операций ≈ 1 секунда. Корректируй × 3–5 для простых операций (арифметика), ÷ 10–100 для тяжёлых (memory-intensive).

### Оценка кода

```cpp
// O(n):
for (int i = 0; i < n; i++) { /* O(1) тело */ }

// O(n²): вложенные циклы
for (int i = 0; i < n; i++)
    for (int j = i; j < n; j++) { /* O(1) тело */ }

// O(n log n): сортировка внутри цикла
for (int i = 0; i < n; i++)
    lower_bound(v.begin(), v.end(), v[i]);  // O(log n) каждый

// O(log n): бинарный поиск
while (lo < hi) { lo = mid + 1; /* или hi = mid */ }  // делит пространство поиска

// O(2^n): перебор подмножеств
for (int mask = 0; mask < (1 << n); mask++) ...

// O(n!): перебор перестановок
std::next_permutation(v.begin(), v.end());
```

### Правила суммирования и умножения

- `O(f) + O(g) = O(max(f, g))` — доминирующий член
- `O(f) × O(g) = O(f × g)` — вложенные циклы
- Константы игнорируются: `O(3n) = O(n)`

### Пространственная сложность

```cpp
// O(1) дополнительная память:
int sum = 0;
for (int x : v) sum += x;

// O(n) дополнительная память:
std::vector<int> result(n);

// O(n) стек рекурсии:
int factorial(int n) { return n <= 1 ? 1 : n * factorial(n-1); }
// глубина рекурсии = n

// O(log n) стек:
void binary_search(lo, hi) {
    if (lo >= hi) return;
    binary_search(lo, mid);
    // глубина = log n
}
```
