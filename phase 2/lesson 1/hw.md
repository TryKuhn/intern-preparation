### A. Оценка сложности кода (около 40 мин)

Для каждого фрагмента определи временну́ю и пространственную сложность. Обоснуй:

```cpp
// 1.
for (int i = 1; i <= n; i *= 2) sum++;

// 2.
for (int i = 0; i < n; i++)
    for (int j = 1; j < n; j *= 2) count++;

// 3. (рекурсивный Фибоначчи)
int fib(int n) { return n<2 ? n : fib(n-1)+fib(n-2); }

// 4. (двоичный поиск)
int lo=0, hi=n-1;
while (lo<=hi) { int mid=(lo+hi)/2; if (a[mid]==x) return mid; else if (a[mid]<x) lo=mid+1; else hi=mid-1; }

// 5.
void f(int n) { if (n<=0) return; f(n/2); f(n/2); }  // T(n) = 2T(n/2) + O(1)

// 6. (bubble sort)
for (int i=0; i<n; i++) for (int j=0; j<n-i-1; j++) if (a[j]>a[j+1]) swap(a[j],a[j+1]);
```
