Цель пре-ридинга — освежить обходы дерева. Около 20 минут.

1. Ничего устанавливать не нужно.
2. Прочитать по диагонали:
    - Pre-order (корень → лево → право), in-order (лево → корень → право), post-order (лево → право → корень).
    - Level-order: обход по уровням через очередь.
3. Подумать над вопросом: in-order обход BST даёт отсортированную последовательность. Почему? Как это использовать для проверки что дерево является BST?
