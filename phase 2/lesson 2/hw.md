### A. Two Pointers (около 50 мин)

1. **LC 167** Two Sum II: два числа с суммой target в отсортированном массиве. O(n), O(1).
2. **LC 11** Container With Most Water: два указателя, максимальная вода. O(n).
3. **Three Sum** (LC 15): все уникальные тройки с суммой 0. O(n²). Подсказка: Sort + фиксировать i, two pointers для j,k.
4. Удалить дубли из отсортированного массива in-place (LC 26). Один указатель — конец уникальных.

### B. Sliding Window (около 40 мин)

1. **LC 209** Minimum Size Subarray Sum: минимальная длина подмассива с суммой ≥ target. O(n).
2. **LC 3** Longest Substring Without Repeating Characters. O(n).
3. **LC 424** Longest Repeating Character Replacement: окно с заменой ≤ k символов. O(n).

### C. Префиксные суммы (около 40 мин)

1. Реализуй `range_sum_query(a, l, r)` за O(1) после O(n) предобработки.
2. Двумерная префиксная сумма: `sum(r1,c1,r2,c2)` за O(1).
3. Найди количество подмассивов с суммой равной k (LC 560). Подсказка: prefix sum + hash map, O(n).
4. Разностный массив: применить m запросов «прибавить val к [l,r]», затем вывести итоговый массив за O(n+m).
