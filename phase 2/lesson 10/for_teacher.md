0–10 мин. Мемоизация.
Подзадачи дублируются: `fib(5)` вызывает `fib(4)` и `fib(3)`, `fib(4)` тоже вызывает `fib(3)`. Запомним результат — каждая подзадача решается только раз. Дерево рекурсии O(2^n) → таблица O(n).

10–40 мин. Паттерны 1D DP.
```cpp
// Лесенка (LC 70): сколько способов подняться на n ступеней по 1 или 2:
// dp[i] = dp[i-1] + dp[i-2]
vector<int> dp(n+1); dp[0]=dp[1]=1;
for (int i=2; i<=n; i++) dp[i] = dp[i-1] + dp[i-2];

// Рюкзак 0/1: n предметов, вместимость W
// dp[j] = max(dp[j], dp[j-w[i]] + v[i])
vector<int> dp(W+1, 0);
for (auto [w,v] : items)
    for (int j=W; j>=w; j--)  // обратный порядок!
        dp[j] = max(dp[j], dp[j-w]+v);
```

40–65 мин. 2D DP.
```cpp
// LCS — длиннейшая общая подпоследовательность:
// dp[i][j] = LCS(s1[0..i), s2[0..j))
vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
for (int i=1; i<=m; i++) for (int j=1; j<=n; j++)
    if (s1[i-1]==s2[j-1]) dp[i][j] = dp[i-1][j-1]+1;
    else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
```
