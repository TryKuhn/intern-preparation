0–10 мин. Идея монотонного стека.
Обсуди: при обходе слева направо, каждый элемент «отвечает» на вопрос всех меньших элементов в стеке. Когда видим новый элемент a[i] > стек.top(), это значит a[i] — «следующий больший» для всех элементов, которые мы вытолкнем из стека.

10–40 мин. Следующий больший элемент.
```cpp
vector<int> next_greater(vector<int>& a) {
    int n = a.size();
    vector<int> res(n, -1);
    stack<int> st;  // стек индексов
    for (int i = 0; i < n; i++) {
        while (!st.empty() && a[st.top()] < a[i]) {
            res[st.top()] = a[i];  // a[i] — следующий больший для st.top()
            st.pop();
        }
        st.push(i);
    }
    return res;
}
```
Инвариант: в стеке всегда убывающая последовательность значений.
Покажи на примере [2,1,5,6,2,3]: рисуй стек шаг за шагом.
