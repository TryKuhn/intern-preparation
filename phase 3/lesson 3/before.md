Цель пре-ридинга — прийти с пониманием HTTP на базовом уровне. Около 25 минут.

1. Проверить что `curl` установлен: `curl --version`. На WSL: `sudo apt install curl`.
   Проверить protoc: `protoc --version`. Если нет: `sudo apt install protobuf-compiler`.
2. Прочитать по диагонали:
    - HTTP методы: GET (читать), POST (создавать), PUT (заменять), PATCH (частично менять), DELETE.
    - Статус-коды: 2xx = успех, 4xx = ошибка клиента, 5xx = ошибка сервера.
    - REST: архитектурный стиль, stateless, ресурсы как URL.
3. Подумать над вопросом: REST stateless — значит сервер не помнит предыдущих запросов. Как тогда реализовать авторизацию?
