### A. Map-Reduce локально (около 50 мин)
1. Реализуй word-count через map-reduce на C++: map (слово → 1), shuffle (группировка по слову), reduce (суммирование). Протестируй на тексте из 1000 строк.
2. Расширь: map-reduce для подсчёта частоты пар слов (bigrams).
3. Добавь многопоточность: несколько потоков выполняют map параллельно, потом один reduce.
