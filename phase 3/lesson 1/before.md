Цель пре-ридинга — прийти с пониманием зачем нужна многопоточность. Около 25 минут.

1. Убедиться что g++ поддерживает C++20: `g++ -std=c++20 --version`. На WSL при необходимости: `sudo apt install g++-11`.
2. Прочитать по диагонали:
    - Что такое поток (thread) и чем отличается от процесса.
    - Race condition (гонка данных): два потока читают/пишут одну переменную без синхронизации.
    - Mutex: взаимное исключение — только один поток в критической секции.
3. Подумать над вопросом (обсудим в начале занятия): если два потока только читают одну переменную без записи — это гонка данных?
