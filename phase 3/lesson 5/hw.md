### A. Schema и SQL (около 40 мин)
1. Создай схему для трекера задач: таблицы `users`, `projects`, `tasks`, `comments`. Используй FOREIGN KEY, SERIAL, CASCADE.
2. Напиши 10 SQL запросов: все незавершённые задачи пользователя, задачи по проекту, статистика per-user, задачи с комментариями (JOIN), задачи за последний день.
3. Добавь индексы на часто используемые WHERE-столбцы. Покажи разницу через `EXPLAIN ANALYZE`.

### B. Транзакции (около 30 мин)
1. Воспроизведи проблему потерянного обновления: два psql-соединения одновременно читают и обновляют одну строку. Покажи что `READ COMMITTED` не решает проблему.
2. Исправь через `SELECT ... FOR UPDATE` или `SERIALIZABLE` уровень.
3. Напиши транзакцию перевода денег между счетами. Убедись что при ошибке (несуществующий счёт) происходит ROLLBACK.

### C. libpqxx приложение (около 60 мин)
Реализуй C++ CLI-приложение для трекера задач:
1. `add <user_id> <title>` — создать задачу.
2. `list <user_id>` — список задач пользователя.
3. `done <task_id>` — отметить выполненной.
4. `delete <task_id>` — удалить.
5. Все операции через libpqxx с параметризованными запросами.
6. Транзакции: `done` и `delete` атомарны.
