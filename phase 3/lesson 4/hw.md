### A. Основы inja (около 40 мин)
1. Рендери строку с: переменной, условием, циклом. Убедись что каждый работает.
2. Создай шаблон `email.txt.tmpl` для приветственного письма: `Dear {{ name }}, your account has been created. Your role: {{ role }}.`
3. Рендери шаблон из файла через `env.render_file()`.
4. Создай HTML-страницу со списком 10 задач (с маркировкой сделанных через CSS класс).

### B. Генерация конфигов (около 40 мин)
1. Напиши шаблон конфига Nginx для нескольких virtual hosts. JSON с полями: домен, порт, список locations. Рендери в корректный nginx.conf.
2. Напиши шаблон CMakeLists.txt для проекта с переменным числом source файлов.
3. Генерируй shell-скрипты из шаблона (deploy.sh.tmpl с переменными: host, port, app_name).

### C. Кодогенерация (около 40 мин)

Задача: напиши генератор C++ структур из JSON-схемы.

Входной файл `schema.json`:
```json
[{"name": "Point", "fields": [{"name": "x", "type": "double"}, {"name": "y", "type": "double"}]},
 {"name": "Color", "fields": [{"name": "r", "type": "uint8_t"}, {"name": "g", "type": "uint8_t"}, {"name": "b", "type": "uint8_t"}]}]
```

Шаблон `struct.hpp.tmpl`:
```
{% for s in structs %}
struct {{ s.name }} {
{% for f in s.fields %}    {{ f.type }} {{ f.name }};
{% endfor %}};
{% endfor %}
```

Реализуй генератор читающий schema.json и рендерящий hpp файл.
