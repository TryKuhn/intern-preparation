### A. Шаблоны (около 50 мин)

1. Напиши шаблон функции `min_element(const Container& c)` возвращающий минимальный элемент. Протестируй на `vector<int>`, `vector<double>`, `vector<string>`.
2. Реализуй шаблонный класс `Pair<T, U>` с полями `first` и `second`. Добавь `make_pair` — шаблонную фабрику.
3. Напиши полную специализацию `min_element` для `std::vector<std::string>` которая сравнивает строки по длине.
4. Используй `if constexpr` для функции `serialize(T val)` которая: для int/double возвращает `std::to_string(val)`, для string возвращает `"\"" + val + "\""`, для bool возвращает `"true"/"false"`.

### B. UB каталог (около 40 мин)

Для каждого примера: опиши что это за UB, скомпилируй с `-fsanitize=undefined` и без, сравни результат:

1. `int arr[5]; arr[10] = 1;` — выход за границы
2. `int x = INT_MAX; x++;` — знаковое переполнение
3. `int* p = nullptr; *p = 5;` — null dereference
4. `int a = 0; int b = a++ + a++;` — модификация + чтение в одном выражении
5. `int x = 5; int* p = &x; bool b = (x != *(reinterpret_cast<int*>(reinterpret_cast<float*>(&x))))` — strict aliasing нарушение (попробуй с `-O2`)

### C. Четыре каста (около 30 мин)

Для каждого написать пример корректного использования и пример UB/ошибки:
1. `static_cast`: правильный downcast vs некорректный.
2. `dynamic_cast`: downcast с проверкой. Покажи что возвращает nullptr при неправильном типе.
3. `const_cast`: снять const с не-const объекта (OK) vs с const объекта (UB).
4. `reinterpret_cast`: для `uintptr_t` (безопасно) vs для алиасинга float как int (UB).

### D. Unspecified vs implementation-defined (около 20 мин)

1. Напиши программу с несколькими побочными эффектами в одном выражении — покажи что порядок не определён.
2. Найди 3 примера implementation-defined поведения в C++ (знаковость char, размер int, порядок байт).
3. Напиши код обнаружения endianness (`is_big_endian()`) через `union` или `memcpy`.
