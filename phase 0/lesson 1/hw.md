### A. Навигация и файлы (около 40 мин)

1. Одной серией команд создай дерево: `course/cpp/`, `course/algo/`, `course/notes/`, `course/notes/archive/` (вспомни `mkdir -p`).
2. В `notes/` создай файлы `day1.md`, `day2.md`, `day3.md`, `draft.md`.
3. Переименуй `day3.md` в `summary.md`, скопируй `summary.md` в `cpp/`, перемести `draft.md` в `notes/archive/`.
4. Командой `find` найди в дереве `course/` все файлы с расширением `.md` и выведи их список.
5. Удали папку `notes/archive/` целиком и проверь `ls`, что её больше нет.
6. Сохрани все использованные команды в файл `commands.txt`.

### B. Поиск и regex (около 90 мин)

Создай файл `data.txt` с содержимым:
```
user1@mail.ru 8-903-540-28-87 active 2024-01-15
admin@yandex.ru 8-999-123-45-67 active 2024-03-02
guest 8-900-000 blocked 2023-12-30
maria.dev@gmail.com 89035402887 active 2024-05-19
broken@@mail 555 blocked 2024-02-11
ivan_petrov@mail.ru 8-912-000-11-22 active 2023-11-01
```
Напиши команды `grep -E` (проверь, что каждая работает), которые:

1. Выводят строки со статусом `active`.
2. Считают через пайп с `wc -l`, сколько строк со статусом `blocked`.
3. Находят строки с email вида что-то, потом `@`, потом домен с точкой.
4. Находят телефоны строго в формате `8-XXX-XXX-XX-XX` (с дефисами, через классы и квантификаторы `{n}`).
5. Выводят строки, где дата в формате `2024-...` (используй якорь и классы).
6. Выводят строки, НЕ содержащие `active` (изучи флаг `grep -v`).
7. Через `sed` замени во всём файле статус `blocked` на `BANNED` и выведи результат (файл не меняй).
8. Через `awk` выведи только первый столбец (email/логин) каждой строки.
9. Со звёздочкой: выведи только строки с корректным email, чтобы `broken@@mail` не попал.
   Сохрани все команды с краткими комментариями и их вывод в `grep-tasks.md`.

### C. Пайпы и редиректы (около 40 мин)

1. Одной цепочкой: взять `data.txt`, оставить только `active`, и записать результат в `active.txt` без вывода на экран.
2. Допиши в конец `active.txt` строку `--- end ---` через `echo` и `>>`.
3. Собери цепочку, которая берёт первый столбец всех строк (`awk`), сортирует (`sort`) и убирает дубли (`uniq`), результат пишет в `logins.txt`.
4. Выполни заведомо ошибочную команду (например `ls nosuchfolder`) и перенаправь её ошибку в файл `errors.txt` через `2>`.
5. В файле `pipes.md` объясни своими словами: чем `>` отличается от `>>`, что делает `2>&1`, и что выведет `false || echo "fail"`.

### D. Скрипты (около 75 мин)

Скрипт 1, `backup.sh`:

1. Принимает имя папки первым аргументом `$1`.
2. Создаёт рядом папку `<имя>_backup` и копирует туда содержимое.
3. Печатает `Готово: скопировано N файлов`, где N получи через `ls | wc -l`.
4. Если аргумент не передан, печатает подсказку по использованию и завершается.

Скрипт 2, `report.sh`:

1. Принимает путь к текстовому файлу первым аргументом.
2. Печатает: сколько всего строк, сколько строк со словом `active`, сколько со словом `blocked` (используй `grep -c` или пайп с `wc -l`).
3. Проверь его на `data.txt`.
   Оба скрипта сделай исполняемыми и проверь работу.

### E. Процессы (около 15 мин)
1. Запусти в фоне команду `sleep 120 &`.
2. Найди её через `ps aux | grep sleep`, определи PID.
3. Заверши её через `kill`. Запиши шаги в `processes.md`.

4. Зачем скрипту нужен shebang?

### Критерий "сделано"
