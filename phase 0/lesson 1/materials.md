### Навигация и файлы

`pwd` — печатает абсолютный путь текущей папки. Первое, что делаешь, когда не понимаешь, где находишься, особенно перед удалением чего-либо.

`ls`, `ls -la` — список содержимого папки. Флаг `-l` даёт подробности (права, размер, дата), `-a` показывает скрытые файлы (имена с точки, например `.gitignore`). Обычно пишут вместе: `ls -la`.

`cd путь` — перейти в папку. `cd ..` поднимает на уровень вверх, `cd ~` ведёт в домашнюю папку, `cd` без аргументов тоже домой.

`mkdir name` — создать папку. `mkdir -p a/b/c` создаёт сразу всю вложенную цепочку, даже если промежуточных папок нет.

`touch file` — создать пустой файл (или обновить дату у существующего).

`cp src dst` — копировать файл. Для папки нужен `cp -r` (рекурсивно, со всем содержимым).

`mv src dst` — переместить файл или папку. Та же команда переименовывает: `mv old.txt new.txt`.

`rm file` — удалить файл. `rm -r dir` удаляет папку с содержимым. Удаление окончательное, корзины нет, поэтому всегда сначала проверь `pwd`.

Пути. Абсолютный путь отсчитывается от корня и начинается со слэша: `/home/maria/proj`. Относительный отсчитывается от текущей папки: `./proj`, `../up`. Обозначения: `.` это текущая папка, `..` родительская, `~` домашняя.

### Просмотр и поиск

`cat file` — вывести весь файл в терминал. Удобно для коротких файлов.

`less file` — открыть файл с прокруткой: стрелки листают, `/слово` ищет, `q` выходит. Для длинных файлов лучше, чем `cat`.

`head -n 20` и `tail -n 20` — показать первые или последние 20 строк. `tail -f log` следит за файлом и дописывает новые строки в реальном времени — так смотрят логи работающего сервиса.

`find . -name "*.cpp"` — рекурсивно искать файлы по маске начиная с текущей папки. Маска `*.cpp` означает любое имя с расширением `.cpp`.

`grep "текст" file` — найти и вывести строки, содержащие текст. Полезные флаги: `-r` рекурсивно по папке, `-n` показывать номера строк, `-i` без учёта регистра. Часто комбинируют: `grep -rni "todo" .`.

### Regex (язык шаблонов) — переиспользуем в C++

Используй `grep -E` (extended), чтобы `+ ? | ( )` работали как метасимволы, а не как обычные буквы.

`.` — любой один символ.

`[abc]` — один символ из перечисленных. `[^abc]` — любой символ, кроме перечисленных. `[a-z]` — диапазон, любая строчная буква.

`[[:digit:]]`, `[[:alpha:]]`, `[[:space:]]` — POSIX-классы: цифра, буква, пробельный символ. Это переносимая запись, работает везде.

`*`, `+`, `?` — повтор предыдущего: ноль или больше раз, один или больше раз, ноль или один раз. Пример: `ab+` это `a` и одна или больше `b`.

`{2}`, `{2,5}`, `{2,}` — точное число повторов: ровно 2, от 2 до 5, от 2 и больше.

`^` и `$` — якоря начала и конца строки. `^abc` совпадёт только если строка начинается с `abc`; `abc$` только если заканчивается на `abc`.

`(...)` — группа, объединяет часть шаблона. `a|b` — альтернатива: подходит `a` либо `b`.

Важно: `\d`, `\w`, `\b` — это синтаксис PCRE (`grep -P`), а не POSIX. В `grep -E` их нет, вместо `\d` пиши `[[:digit:]]`. Но именно `\d`/`\w` встретятся в `std::regex` (грамматика ECMAScript) — там этот синтаксис как раз поддерживается.

Жадность: `.*` по умолчанию хватает как можно больше символов. Это поведение по умолчанию у всех квантификаторов.

Замена и колонки (для общего знакомства): `sed 's/старое/новое/g'` заменяет текст, `awk '{print $1}'` печатает первую колонку строки.

### Пайпы и редиректы

`a | b` — пайп: вывод команды `a` становится вводом команды `b`. Так из мелких команд собирают цепочки.

`wc -l` — посчитать число строк во вводе. `sort` — отсортировать строки, `uniq` — убрать соседние дубли (часто ставят после `sort`). Пример цепочки: `cat app.log | grep -E "ERROR" | wc -l` посчитает строки с ошибками.

`>` — перенаправить вывод в файл с перезаписью (старое содержимое стирается). `>>` — дописать в конец, не стирая. `<` — взять ввод из файла.

`2>` — перенаправить поток ошибок отдельно. `2>&1` — слить ошибки в тот же поток, что и обычный вывод (нужно, когда хочешь видеть и то и другое вместе).

`&&` и `||` — условные цепочки: `a && b` выполнит `b`, только если `a` отработала успешно; `a || b` выполнит `b`, только если `a` завершилась ошибкой.

### Права и запуск

`ls -l` показывает права в виде `rwx`, отдельно для трёх категорий: владелец (user), группа (group), остальные (other). Буквы означают read, write, execute.

`chmod +x script.sh` — добавить право на исполнение, без него скрипт не запустится. Октальная форма `chmod 755` задаёт права числом: 7 это rwx владельцу, 5 это r-x группе и остальным.

### Процессы

`ps aux | grep имя` — найти запущенный процесс по имени.

`top` — живой список процессов с нагрузкой, выход по `q`.

`kill PID` — попросить процесс завершиться по его номеру (PID). `kill -9 PID` — завершить жёстко, если не реагирует.

`команда &` — запустить в фоне, терминал сразу свободен. `Ctrl+C` прерывает текущую команду, `Ctrl+Z` приостанавливает её.

### Переменные окружения и первый скрипт

`echo $PATH` печатает список папок, в которых shell ищет команды. Когда ты пишешь `ls`, shell ищет файл `ls` по этим папкам. `export VAR=value` задаёт переменную окружения.

```bash
#!/bin/bash          # shebang: каким интерпретатором запускать файл
name="$1"            # первый аргумент командной строки
echo "Привет, $name!"
```

Запуск: `chmod +x hello.sh`, затем `./hello.sh Maria`. Префикс `./` обязателен, потому что текущей папки нет в `$PATH`, и иначе shell не найдёт скрипт.
