### A. sizeof и типы (около 30 мин)

1. Напиши программу, которая выводит `sizeof` для всех базовых типов: `char`, `short`, `int`, `long`, `long long`, `float`, `double`, `size_t`, `nullptr_t`, `std::string`. Запиши результаты.
2. Используй `<climits>` и `<cfloat>`, выведи `INT_MAX`, `INT_MIN`, `UINT_MAX`, `LLONG_MAX`, `FLT_MAX`, `DBL_EPSILON`.
3. Напиши функцию `print_size(const char* name, auto value)` используя шаблон или перегрузки — пусть красиво выводит имя типа и его размер. Используй `typeid(value).name()`.

### B. Ловушки целых чисел (около 60 мин)

Каждый пункт: сначала угадай результат, потом проверь программой.

1. `int x = INT_MAX; x++; printf("%d\n", x);` — что выведет? Скомпилируй с `-fsanitize=undefined` и без. Сравни.
2. `unsigned int u = 0; u--;` — чему равен `u`?
3. `int x = -1; unsigned int y = 0; printf("%d\n", x < y ? 1 : 0);` — ожидаешь 1, получаешь?
4. `char c = 200; int i = c;` — чему равен `i`? А если изменить на `unsigned char`?
5. Напиши функцию `safe_add(int a, int b)` которая возвращает `std::optional<int>` — `std::nullopt` если сложение переполнится. Используй `__builtin_add_overflow` или проверку через границы.
6. Убывающий цикл `for (size_t i = v.size()-1; i >= 0; i--)`: воспроизведи бесконечный цикл, зафикси проблему, исправь через `int` или обратный итератор.

### C. float и сравнения (около 30 мин)

1. Выведи `0.1 + 0.2` и сравни с `0.3` через `==` и через epsilon. Напиши универсальный `approx_equal(double a, double b, double eps = 1e-9)`.
2. `float nan = NAN; bool b = nan == nan;` — что такое NaN, почему `nan != nan`? Используй `std::isnan`.
3. Выведи `std::numeric_limits<float>::epsilon()` — что это значит?
4. Напиши функцию, которая принимает `double` и возвращает `true` если значение является целым числом. Учти NaN и бесконечность.

### D. Sanitizers (около 30 мин)

1. Напиши программу с намеренным signed overflow. Скомпилируй с и без `-fsanitize=undefined`. Покажи разницу в выводе.
2. Напиши программу с выходом за пределы массива. Запусти с `-fsanitize=address`. Найди строку с ошибкой в выводе.
3. Добавь флаги sanitizers в `CMakeLists.txt` через `target_compile_options` только для Debug-конфигурации.

### Самопроверка (около 20 мин, письменно в `selfcheck.md`)

1. Чем стек отличается от кучи? Когда использовать одно, когда другое?
2. Почему знаковое переполнение — UB, а беззнаковое — нет?
3. Что произойдёт в выражении `(int)(-1) < (unsigned int)(0)`?
4. Почему `char c = 'A'; sizeof(c + c)` равен 4, а не 1?
5. `for (size_t i = n-1; i >= 0; i--)` — в чём баг? Как исправить?
6. Можно ли доверять `float == float`? Когда это допустимо?
7. Что такое `NaN` и почему `NaN != NaN`?
