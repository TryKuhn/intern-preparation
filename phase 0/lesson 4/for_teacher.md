0–5 мин. Зачем это всё.
Обсуди вопрос: `INT_MAX + 1` — это Undefined Behavior в C++. Компилятор вправе предположить, что это никогда не произойдёт, и оптимизировать код соответствующим образом. Это реальный класс багов в production-коде (например, CVE в ядре Linux). Понимание памяти и типов — фундамент написания корректного кода.

5–25 мин. Стек vs куча.
Нарисуй на бумаге пространство памяти процесса: code, globals/BSS, heap (снизу вверх), stack (сверху вниз).
- **Стек**: автоматически управляемый. Переменная живёт от `{` до `}`. Размер фиксируется в момент объявления. Быстро (просто смещение указателя стека).
- **Куча**: ручное управление (new/delete) или умные указатели. Размер может быть произвольным. Медленнее.
Покажи: `int x = 5;` — на стеке. `int* p = new int(5);` — на куче. Адрес `p` — на стеке, `*p` — на куче.
`sizeof`: покажи `sizeof(int)`, `sizeof(char)`, `sizeof(double)`, `sizeof(std::string)`. Пусть угадает перед запуском.
`size_t` — беззнаковый целый тип, достаточно большой для размера объекта или индекса. Возвращается `sizeof` и методами контейнеров.

25–50 мин. Целые типы — ловушки.
```cpp
// Показывай каждый пример, пусть угадает результат
int8_t x = 127;
x++;  // -128! Знаковое переполнение — UB
printf("%d\n", x);  // может работать, может нет, может что угодно
```
- **Знаковое переполнение = UB**: компилятор вправе оптимизировать `if (x + 1 > x)` в `if (true)`. Это реальная оптимизация, которую делает GCC.
- **Беззнаковое оборачивается**: `uint8_t(255) + 1 == 0` — это определённое поведение, гарантировано стандартом.
- Ловушка: `-1 < 0u` → false! Причина: `-1` продвигается до `unsigned`, становится UINT_MAX.
- Целочисленные промоушены: `char + char` → `int`. Покажи `sizeof('A' + 'B')` — это 4 (int), не 1.
- `size_t` в цикле: `for (size_t i = v.size()-1; i >= 0; i--)` — бесконечный цикл при пустом векторе!
```cpp
vector<int> v;
for (size_t i = v.size() - 1; i >= 0; i--)  // v.size()-1 = UINT_MAX если пустой!
```
Покажи с AddressSanitizer или просто выведи `i`.

50–65 мин. char и float.
- `char`: знаковый или беззнаковый — implementation-defined. Проверить: `char c = 200; (int)c` — может быть -56 или 200 в зависимости от платформы. Для текста использовать `unsigned char` или `uint8_t` если важна знаковость.
- `float`: `0.1 + 0.2 != 0.3` — показать в коде. IEEE 754, конечная точность. Никогда не сравнивай `float == float` напрямую.
- NaN: `float nan = std::numeric_limits<float>::quiet_NaN(); nan == nan` → false! NaN не равен ничему, включая себя.

65–80 мин. Практика с sanitizers.
Включи `-fsanitize=undefined -fsanitize=address` в g++. Покажи как sanitizers находят:
1. Знаковое переполнение.
2. Выход за пределы массива.
Sanitizers — первый инструмент при непонятных багах.

80–90 мин. Выдача ДЗ.
