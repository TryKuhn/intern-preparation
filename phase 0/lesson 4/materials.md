### Стек и куча

Процесс получает от ОС виртуальное адресное пространство. Внутри него:
- **Стек** — автоматическая память. Каждый вызов функции создаёт «фрейм» с локальными переменными. Фрейм уничтожается при возврате. Размер — обычно 1–8 МБ.
- **Куча** — динамическая память. Выделяется через `new`/`malloc`, освобождается через `delete`/`free`. Практически неограниченный размер (в пределах RAM).

```cpp
void foo() {
    int x = 42;          // стек — уничтожится при выходе из foo
    int* p = new int(7); // p (указатель) на стеке, *p на куче
    delete p;            // надо освободить вручную
}
```

`sizeof(T)` — размер в байтах. Вычисляется на этапе компиляции. `size_t` — беззнаковый тип, возвращаемый `sizeof` и `.size()` контейнеров.

### Целые числа — ключевые тонкости

**Диапазоны стандартных типов** (gарантированы стандартом, точные размеры в `<cstdint>`):
| Тип | Минимум | Максимум |
|---|---|---|
| `int8_t` | -128 | 127 |
| `uint8_t` | 0 | 255 |
| `int32_t` | -2 147 483 648 | 2 147 483 647 |
| `uint32_t` | 0 | 4 294 967 295 |

**Знаковое переполнение = UB:**
```cpp
int x = INT_MAX;
x = x + 1;  // Undefined Behavior! Компилятор вправе убрать эту ветку целиком.
```
Беззнаковое переполнение — определённое поведение, оборачивается по модулю.

**Ловушка: сравнение знакового и беззнакового:**
```cpp
int x = -1;
unsigned int y = 0;
if (x < y) { ... }  // НЕ выполнится: -1 промотируется до UINT_MAX
```
Компилятор часто предупреждает об этом. Никогда не смешивать signed/unsigned без явного приведения.

**Целочисленные промоушены:**
```cpp
char a = 1, b = 2;
auto c = a + b;     // c имеет тип int, а не char!
sizeof(a + b);      // 4 (размер int), не 1
```
Типы меньше `int` автоматически повышаются до `int` в арифметических выражениях.

**size_t в убывающем цикле — подтекание:**
```cpp
std::vector<int> v = {};
for (size_t i = v.size() - 1; i >= 0; i--) {  // БЕСКОНЕЧНЫЙ ЦИКЛ!
    // v.size() == 0, 0 - 1 == SIZE_MAX для беззнакового типа
}
// Правильно: использовать int или цикл с другим условием
for (int i = (int)v.size() - 1; i >= 0; i--) { ... }
```

### char и знаковость

Знаковость `char` — implementation-defined: на x86/x64 обычно знаковый, на ARM — беззнаковый. Для бинарных данных или когда важна знаковость — использовать явно `signed char` или `unsigned char` (они — разные типы!).

### float — тонкости

```cpp
// Никогда не сравнивай float через ==:
float a = 0.1f + 0.2f;
if (a == 0.3f) { ... }  // НЕВЕРНО — не выполнится

// Правильно: epsilon-сравнение
if (std::abs(a - 0.3f) < 1e-6f) { ... }

// NaN не равен ничему, даже себе:
float nan = std::numeric_limits<float>::quiet_NaN();
bool b = (nan == nan);  // false!
bool c = std::isnan(nan);  // true
```

### AddressSanitizer и UBSanitizer

```bash
g++ -fsanitize=address,undefined -g -O1 program.cpp -o program
./program
# При нарушении — подробный отчёт с местом в коде
```

Включай sanitizers при разработке и тестировании. Они находят:
- Выход за пределы массива
- Use-after-free
- Знаковое переполнение (UBSan)
- Нулевой дереференс
