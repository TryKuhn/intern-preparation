### A. Воспроизвести и поймать баги (около 50 мин)

Для каждого пункта: напиши программу, скомпилируй с `-fsanitize=address -g`, запусти, прочитай и объясни вывод sanitizer'а.

1. **Утечка**: создай `new int[100]`, не освобождай, завершись. Найди утечку через valgrind (`--leak-check=full`) или ASan.
2. **Use-after-free**: выдели `new int(5)`, сделай `delete`, попробуй прочитать. Что говорит ASan?
3. **Double-free**: выдели, освободи, освободи снова.
4. **delete вместо delete[]**: `new int[5]`, потом `delete` (без квадратных скобок).
5. **Стек-overflow**: напиши рекурсию без базового случая (но не на слабом железе!). Покажи что ошибка другая — не heap, а стек.

### B. Класс с ручным управлением памятью (около 60 мин)

Реализуй класс `Buffer` — обёртка над динамическим массивом char:
```cpp
class Buffer {
public:
    Buffer(size_t size);
    ~Buffer();
    char& operator[](size_t i);
    size_t size() const;
    // Запрети копирование (= delete)
private:
    char* data_;
    size_t size_;
};
```
1. Реализуй конструктор (new[]) и деструктор (delete[]).
2. Добавь `operator[]` с проверкой границ через `assert`.
3. Запрети copy constructor и copy assignment через `= delete`.
4. Протестируй: создай Buffer, запиши данные, прочитай, убедись что destructor вызывается.
5. Запусти под `-fsanitize=address`. Намеренно выйди за границу — убедись что ASan поймает.

### C. Выравнивание и паддинг (около 30 мин)

3. Создай `alignas(64) char cache_buf[64]` — проверь что адрес кратен 64.
