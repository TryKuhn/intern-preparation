### A. Передача параметров (около 35 мин)

1. Напиши три версии функции `swap`: по значению (не работает), по ссылке (работает), по указателю (работает). Убедись что версия по значению действительно не меняет оригинал.
2. Напиши функцию `find_max(const std::vector<int>& v)` которая возвращает `const int*` — указатель на максимальный элемент, или `nullptr` если вектор пуст. Используй в main, разыменуй результат.
3. Напиши `scale(std::vector<double>& v, double factor)` которая умножает все элементы на factor. Сравни с версией принимающей `std::vector<double> v` по значению — замерь время на большом векторе (1 000 000 элементов).

### B. Указатели и арифметика (около 40 мин)

1. Объяви массив `int arr[10]` и через арифметику указателей (без `[]`) напиши цикл заполнения числами 0..9 и цикл вывода.
2. Напиши функцию `my_strlen(const char* s)` — длина C-строки без `strlen`. Используй арифметику указателей.
3. Напиши `my_memcpy(char* dst, const char* src, size_t n)`. Убедись что работает для непересекающихся буферов.
4. `sizeof(arr)` vs `sizeof(p)` где `p = arr` — выведи оба. Объясни почему разные.
5. Запусти с `-fsanitize=address` функцию, которая возвращает указатель на локальную переменную. Что выводит sanitizer?

### C. Категории значений и ссылки (около 35 мин)

1. Для каждого выражения определи категорию (lvalue / rvalue) и объясни:
   `x`, `x + 1`, `arr[2]`, `*p`, `"hello"`, `std::move(x)`, `(x)`
2. Напиши функцию `int& get_elem(std::vector<int>& v, int i)` — возвращает lvalue-ссылку. Убедись что через неё можно изменить элемент: `get_elem(v, 0) = 42;`
3. Попробуй привязать lvalue-ссылку к rvalue: `int& r = 5;` — покажи ошибку. Затем `const int& cr = 5;` — почему это работает?
4. Напиши функцию возвращающую `const std::string&` где ссылка ссылается на локальную строку. Покажи что sanitizer ловит висячую ссылку.

### D. auto и decltype (около 20 мин)

const int cx = 5;
int& rx = x;
