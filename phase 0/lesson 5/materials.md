### Три способа передачи параметров

```cpp
void by_value(int x)        { x = 100; }    // копируется — оригинал не меняется
void by_ref(int& x)         { x = 100; }    // ссылка — меняет оригинал
void by_ptr(int* x)         { *x = 100; }   // указатель — тоже меняет, другой синтаксис
void by_const_ref(const int& x) { /* x = 100; */ } // запрещено изменять
```

**Когда что использовать:**
- Входной параметр, большой объект → `const T&` (без копии, без изменений)
- Нужно изменить объект → `T&`
- Параметр необязателен (может не передаваться) → `T*` (проверить на `nullptr`)
- Владение → `std::unique_ptr<T>` (следующий урок)

### Указатели: основы

```cpp
int x = 42;
int* p = &x;     // p хранит адрес x
*p = 100;        // изменить x через указатель (разыменование)
int** pp = &p;   // указатель на указатель
int* null = nullptr;  // нулевой указатель
// *null = 5;    // UB — segfault
```

### Арифметика указателей и распад массива

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;       // arr "распадается" в &arr[0]

*(p + 2) == p[2] == arr[2] == 30  // эквивалентные записи

p++;                // p указывает на arr[1]
p += 2;             // p указывает на arr[3]
```

Исключения: `sizeof(arr)` возвращает полный размер массива (20 байт для int[5]), не размер указателя. `&arr` имеет тип `int(*)[5]`, а не `int*`.

**Строковые литералы**: `"hello"` — это `const char*`, указатель на статическую память.

### Категории значений

| Категория | Описание | Пример |
|---|---|---|
| **lvalue** | Имеет имя и адрес, «стоит слева» | `x`, `arr[i]`, `*p` |
| **prvalue** | Временное, нет адреса | `42`, `x + y`, `foo()` |
| **xvalue** | «Умирающий» объект, можно переместить | `std::move(x)` |
| **glvalue** | lvalue или xvalue | — |
| **rvalue** | prvalue или xvalue | — |

Практически важно:
```cpp
int x = 5;
int& r = x;       // OK: lvalue-ссылка к lvalue
int& r2 = 5;      // ОШИБКА: нельзя привязать lvalue-ссылку к rvalue
const int& cr = 5; // OK: const lvalue-ссылка может привязаться к rvalue (продлевает жизнь)
int&& rr = 5;     // OK: rvalue-ссылка к rvalue (временному значению)
```

### Висячие ссылки (dangling references)

```cpp
int& dangling_ref() {
    int local = 42;
    return local;   // ОШИБКА: local уничтожается при выходе из функции
}

int* dangling_ptr() {
    int local = 42;
    return &local;  // ОШИБКА: аналогично
}

// Тихий UB — компилятор выдаст предупреждение, но не ошибку
```

### Продление жизни temporary

```cpp
// Привязка const-ссылки к временному продлевает его жизнь:
const int& r = expensive_computation();  // temporary живёт до конца области видимости r
// Это легально и используется на практике
```

### `auto` vs `decltype`

```cpp
int x = 5;
const int cx = 5;
int& rx = x;

auto a = x;       // int (значение)
auto b = cx;      // int (const отброшен!)
auto c = rx;      // int (ссылка отброшена!)

decltype(x)  d1 = x;  // int
decltype(cx) d2 = x;  // const int
decltype(rx) d3 = x;  // int& (ссылка сохранена!)

// decltype((x)) — скобки меняют тип! (x) — lvalue-выражение → int&
```

**Правило**: `auto` выводит «голый» тип (без top-level const и ссылок). `decltype` возвращает точный тип выражения.
