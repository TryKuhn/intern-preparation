0–5 мин. Зачем это всё.
Обсуди вопрос: ссылки не могут быть нулевыми, не могут быть переназначены, не поддерживают арифметику. Указатели — могут всё это. Нужны для динамических структур данных (связные списки, деревья), optional-параметров (может быть nullptr), массивов, C API. В современном C++ сырые указатели — почти всегда «наблюдающие», без владения.

5–25 мин. Три способа передачи параметров.
```cpp
void by_value(int x)   { x = 100; }     // копия
void by_ref(int& x)    { x = 100; }     // изменяет оригинал
void by_ptr(int* x)    { *x = 100; }    // изменяет оригинал через разыменование
```
Покажи в отладчике адреса. Покажи что `by_value` меняет копию. Измени через ссылку и через указатель — разная синтаксис, одинаковое поведение.
Правило: для входных параметров — `const T&` (избегает копирование). Для изменяемых — `T&`. Для optional или nullable — `T*`. Для владения — `std::unique_ptr<T>`.

25–45 мин. Арифметика указателей и распад массива.
```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;   // arr "распадается" в указатель на первый элемент
p[2];           // == *(p + 2) == 30
```
Ключевое: `arr` в выражениях — это `int*`, адрес первого элемента. Исключение: `sizeof(arr)` и `&arr` — не распадается.
Покажи `p++` — передвигается не на 1 байт, а на `sizeof(int)` байт.
`nullptr`: единственное нулевое значение указателя. `NULL` — устаревший синоним. Разыменование nullptr — UB (segfault).

45–65 мин. Категории значений lvalue/rvalue.
Это фундамент для следующих уроков (перемещение, форвардинг). Начни с простого:
- **lvalue**: «то, что стоит слева от `=`», имеет имя и адрес. `int x = 5;` — `x` это lvalue.
- **rvalue**: временное значение, нельзя взять адрес. `5`, `x + y`, `foo()` (если возвращает по значению).
Строго: glvalue/prvalue/xvalue — упомяни, но не углубляйся. Главное что надо знать: rvalue-ссылка `T&&` привязывается к временным объектам.
Практика: `int& r = 5;` — ошибка (rvalue к lvalue-ссылке). `const int& cr = 5;` — ок (особое правило!).

65–80 мин. Висячие ссылки, const& продление жизни, auto vs decltype.
```cpp
int& dangling() {
    int local = 42;
    return local;  // ОШИБКА: возвращаем ссылку на уничтоженный объект
}
```
Висячая ссылка — UB. Компиляторы предупреждают, но не всегда.

Продление жизни temporary:
```cpp
const int& r = foo_returns_int();  // temporary живёт пока жива r
int& r2 = foo_returns_int();       // ОШИБКА: нельзя
```

`auto` vs `decltype`:
```cpp
int x = 5;
int& rx = x;
auto a = rx;      // a — int (ссылка отброшена)
decltype(rx) d = x; // d — int& (тип сохранён точно)
const int cx = 5;
auto b = cx;      // b — int (const отброшен)
```

80–90 мин. Выдача ДЗ.
