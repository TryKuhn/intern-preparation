### A. MinHeap реализация (около 70 мин)

1. Реализуй `MinHeap<T>` с push, pop, top, empty, size.
2. Добавь `build(vector<T>)` — O(n) построение из массива.
3. Реализуй `heap_sort(vector<T>&)` через MinHeap.
4. Добавь `contains(const T&)` — O(n) поиск (не оптимально, но полезно для теста).
5. `decrease_key(size_t i, T new_val)` — уменьшить ключ элемента на позиции i.

### B. Задачи на куче (около 40 мин)

1. **K наибольших элементов** из потока: используй min-heap размера k.
2. **Слить k отсортированных массивов** в один: используй min-heap из k элементов.
3. **Медиана потока**: два heap — max-heap для нижней половины, min-heap для верхней. O(log n) на вставку, O(1) для медианы.

### C. Сравнение (около 20 мин)

1. Замерь время 1 000 000 push + 1 000 000 pop для MinHeap vs `std::priority_queue`. Сравни.
2. Покажи через код что build_heap O(n) быстрее чем n push O(n log n).
