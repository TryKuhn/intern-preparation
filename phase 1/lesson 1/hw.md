### A. Тур по контейнерам (около 40 мин)

1. Напиши программу читающую слова из stdin и считающую частоту каждого слова. Реализуй через `unordered_map<string, int>`. Затем выведи топ-10 слов по частоте через `priority_queue`.
2. Реализуй то же через `map` — сравни код и поведение (map всегда отсортирован).
3. Заполни `vector<int>` числами 1..1000000. Замерь время `push_back` с и без `reserve(1000000)`. Объясни разницу.
4. Попробуй инвалидацию итератора: сохрани итератор на элемент вектора, вызови `push_back`, проверь через `-fsanitize=address` что итератор теперь невалиден (или убедись что reserve предотвращает это).

### B. Алгоритмы и лямбды (около 40 мин)

1. Дан `vector<string>` с именами. Отсортируй: а) лексикографически, б) по длине, в) по последнему символу. Используй лямбды-компараторы.
2. Напиши функцию `transform_pipeline(vector<int> v)` которая цепочкой: фильтрует чётные, умножает на 3, удаляет дубли. Используй `remove_if`, `transform`, `unique` из `<algorithm>`.
3. Реализуй `group_by(vector<T> v, auto key_fn)` → `unordered_map<Key, vector<T>>` через лямбду-ключ.
4. Напиши lambda которая захватывает `shared_ptr<int>` (не `this` напрямую) чтобы гарантировать живость объекта. Продемонстрируй что объект не удаляется пока лямбда жива.

### C. string_view, optional, variant (около 30 мин)

1. Напиши функцию `split(std::string_view sv, char delim) → vector<string_view>`. Убедись что никаких копий строк нет.
2. Напиши `optional<std::pair<int,int>> parse_range(string_view s)` парсящую строку вида `"10-20"`. Возвращает nullopt при неверном формате.
3. Реализуй калькулятор выражений через `variant<int, double, std::string>` — каждое значение может быть одного из типов. Используй `std::visit` для dispatch.

### D. std::regex (около 20 мин)

1. Напиши `validate_email(string_view)` и `validate_phone(string_view)` используя regex. Протестируй на корректных и некорректных строках.
2. Из строки `"2024-01-15 user@mail.ru ERROR timeout"` извлеки через regex: дату, email, уровень лога, сообщение. Используй группы захвата `smatch`.

4. Чем `optional<T>` лучше `T*` для optional-значений?
