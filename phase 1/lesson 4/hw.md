### A. Stack (около 40 мин)

1. Реализуй `Stack<T>` через `std::vector` (как в materials).
2. Реализуй `Stack<T>` через `SinglyLinkedList` из предыдущего урока.
3. Используй стек для задачи «проверка скобочной последовательности»: `{[()]}` → true, `{[}]` → false.
4. Реализуй «stack с поддержкой min» — `MinStack<T>` с O(1) `push`, `pop`, `top`, `min`. Подсказка: используй два стека.

### B. CircularQueue (около 50 мин)

1. Реализуй `CircularQueue<T>` с фиксированной capacity.
2. Добавь автоматическое расширение: если заполнен → удвоить capacity (скопировать элементы, исправить индексы).
3. Реализуй `Deque<T>` (двусторонняя очередь) на кольцевом буфере: `push_front`, `push_back`, `pop_front`, `pop_back` — все O(1).

### C. Применение (около 30 мин)

1. Реализуй «следующий больший элемент» через монотонный стек (preview алго-фазы): для каждого элемента массива найди следующий больший. O(n).
2. «Горячая картошка» через Queue: n игроков в кольце, каждый k-й выбывает — кто последний?
