Цель пре-ридинга — прийти с установленным Docker. Около 20 минут.

1. Проверить: `docker --version` и `docker run hello-world`. Если Docker не установлен — Docker Desktop (Windows/Mac) или `sudo apt install docker.io` (Linux/WSL2).
2. Прочитать по диагонали:
    - Образ (image): неизменяемый шаблон. Контейнер: запущенный экземпляр образа.
    - Dockerfile: инструкции по сборке образа.
    - Слоистая архитектура: каждая инструкция — слой, кешируется.
3. Подумать над вопросом: контейнер — это не виртуальная машина. Что именно изолировано между контейнерами? Что они разделяют с хостом?
