Цель пре-ридинга — прийти с рабочими make и cmake. Около 20 минут.

1. Проверить инструменты:
   - `make --version` (должна быть установлена)
   - `cmake --version` (хотя бы 3.15)
   - На Windows/WSL: `sudo apt install make cmake`
2. Прочитать по диагонали:
    - Что делает `make`: читает Makefile, строит цели по зависимостям.
    - Инкрементальная сборка: make пересобирает только изменившееся (по timestamp файлов).
3. Подумать над вопросом: если `make` строит по временным меткам файлов, что произойдёт если ты просто выполнишь `touch main.cpp` без изменений? Пересоберёт ли make программу?
